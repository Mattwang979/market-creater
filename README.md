# 熱度交易所 Market Creater

一款以「造市套利」為核心的網頁遊戲。選一個商品、讓系統初步定價，再透過你的策略把冷清的市場一步步經營到熱絡；流動性越高，能用的套利手法就越多。

直接用瀏覽器打開 `index.html` 就能玩，手機和電腦都可以，進度會自動存在瀏覽器裡。

## 核心循環

1. **選商品**：7 種商品各有優勢與風險，例如保溫杯不會壞但週轉慢、宵夜便當需求爆量但 8 小時就報廢、雨衣只在下雨時大賣。
2. **系統定價**：依開店地點估算合理價，給出建議收購價、售價、營業時間與進貨目標。
3. **養流動性**：市場從「冷清」開始。窄價差、穩定供貨、充足庫存與現金、人潮、價格平穩和好口碑會讓流動性上升；被套利客反覆吃單（毒性）、缺貨、撤單、價格劇烈波動和恐慌事件會讓流動性枯竭。
4. **解鎖套利**：起步（拉抬買盤、出清拋售）→ 活絡（跨區調貨）→ 熱絡（吃對手單）→ 沸騰（撮合大單、預售合約）。

## 主要規則

- 客人只在營業時間上門，供應商只在打烊後來；營業越久人力成本越高。
- 尖峰時段報價會鎖住，要在離峰或打烊時調整，或啟用智慧報價機。
- 生鮮商品有保存期限，可用進貨目標、即期折扣、冷鏈設備和出清拋售管理報廢風險。
- 大量溢價買進會推高價格並吸引追漲客，但回歸套利客會把價格壓回合理價，頻繁拉抬會被主管機關約談。
- 隨機事件包含新聞、天氣、區域活動、各類別商品事件、價格戰、港口罷工、大單和恐慌拋售。
- 打開策略頁時遊戲會自動暫停。

## 發佈到 GitHub Pages

到儲存庫的 Settings › Pages，Source 選擇 `main` 分支的根目錄，幾分鐘後就能從 `https://<你的帳號>.github.io/market-creater/` 進入遊戲。

## 技術

單一 HTML 檔案，純 JavaScript 與 Canvas 繪製，人物、商品與地圖都是程式繪製。字型來自 Google Fonts。
