# 熱度交易所 Market Creater

一款以「造市商」為主題的網頁遊戲。你在城市各區擺攤，同時掛出收購價和售價，讓想買的客人和想賣的供應商都能成交，靠提供流動性賺取價差。

## 怎麼玩

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝任何東西。手機和電腦都可以。

- 市場二十四小時不停運作，有白天也有黑夜，每種商品有自己的交易時段。
- 尖峰時段報價會鎖住，要在離峰或休市時先調好，或者啟用智慧報價機。
- 城市分成大學城、商辦區、住宅區、老街和港口，每一區住著不同族群，人潮時段也不同。
- 市場熱度由人流、流動性（口碑）、價格和隨機事件共同推動，畫面下方的即時圖表會顯示是哪個因素在帶動。
- 客人只會跟價格較好的一方成交；缺貨、撤單或報價輸給對手，口碑就會下滑。
- 新聞、天氣、廟會、網紅打卡、價格戰、港口罷工、大單和恐慌拋售會隨機出現，套利客會吃掉落後的報價。

## 增加流動性與銷量的策略

限時優惠、社群廣告、批發進貨、延長營業、撤單、造市承諾、會員集點、網紅合作、智慧報價機，另外還能開新攤位、替攤位換商品，以及研發自己的商品（自訂屬性、包裝、顏色與交易時段）。

## 進度

遊戲進度會自動存在瀏覽器的 localStorage 裡，關掉頁面後回來可以繼續。

## 發佈到 GitHub Pages

1. 把 `index.html` 和這份 `README.md` 放到儲存庫根目錄。
2. 到儲存庫的 Settings › Pages，Source 選擇 `main` 分支的根目錄。
3. 幾分鐘後就能從 `https://<你的帳號>.github.io/market-creater/` 進入遊戲。

## 技術

單一 HTML 檔案，純 JavaScript 與 Canvas 繪製，人物、商品與地圖都是程式繪製，沒有使用圖片或表情符號。字型來自 Google Fonts。
